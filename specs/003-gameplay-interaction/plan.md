# Implementation Plan: Gameplay Interaction

**Branch**: `003-gameplay-interaction` | **Date**: 2026-06-03 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-gameplay-interaction/spec.md`

## Summary

Add gameplay interaction to existing game rooms: an HTML5 Canvas for the drawer to draw on, guess submission with case-insensitive validation, scoring (100 points per correct guess, once per round), and polling synchronization. All endpoints extend the existing Express router and in-memory Room store. No WebSockets.

## Technical Context

**Language/Version**: TypeScript 5.x (Node.js 20+)

**Primary Dependencies**: Express 4.x, Zod 3.x, React 18, Vite 5

**Storage**: In-memory `Map<string, Room>` in `backend/src/services/roomStore.ts`. No databases.

**Testing**: Vitest (existing pattern in `roomStore.test.ts`, `schemas.test.ts`)

**Target Platform**: Node.js HTTP server (`localhost:3001`), React frontend (`localhost:5173`)

**Project Type**: Web application (Express backend + React/Vite frontend)

**Performance Goals**: Canvas stroke submission and guess responses within the 2-second polling window. No real-time requirement — drawings update on next poll.

**Constraints**: 
- No WebSockets/Socket.io — HTTP polling only (POL-1)
- No databases — in-memory only (MEM-1)
- No authentication (project constraint)
- Zod validation on all request payloads (VAL-1)
- TypeScript strict mode, no `any` (TS-1)

**Scale/Scope**: ~2–8 players per room, single-process Node.js server

## Technical Design

### Backend

#### 1. Model Changes (`models/game.ts`)

Add `Guess` interface and extend `Room`, `Participant`, `RoomSnapshot`:

```typescript
export interface Point {
  x: number;
  y: number;
}

export interface Guess {
  id: string;
  participantId: string;
  text: string;              // trimmed
  isCorrect: boolean;
  awardedPoints: number;     // 100 or 0
  timestamp: string;
}

// On Participant (add to existing):
export interface Participant {
  // ...existing fields
  score: number;              // NEW — cumulative points, default 0
  hasScoredThisRound: boolean;// NEW — guard, default false
}

// On Room (add to existing):
export interface Room {
  // ...existing fields
  strokes: { points: Point[] }[];  // NEW — array of finalized strokes
  guesses: Guess[];                 // NEW — array of submitted guesses
}

// On RoomSnapshot (add to existing):
export interface RoomSnapshot {
  // ...existing fields
  strokes: { points: Point[] }[];  // NEW
  guesses: Guess[];                 // NEW
}
```

#### 2. Room Service Changes (`services/roomStore.ts`)

**`appendStroke(code, participantId, points)`**:

```
1. Validate: room exists, room.status === "game"
2. Validate: participantId === drawerId (403 if not drawer)
3. Append { points } to room.strokes
4. Save room, return updated snapshot
```

**`clearCanvas(code, participantId)`**:

```
1. Validate: room exists, room.status === "game"
2. Validate: participantId === drawerId (403 if not drawer)
3. Set room.strokes = []
4. Save room, return updated snapshot
```

**`submitGuess(code, participantId, text)`**:

```
1. Validate: room exists, room.status === "game"
2. Find participant; ensure role === "guesser" (403 if drawer or unknown)
3. Trim text. Reject if empty string (400).
4. Case-insensitive match: guess.toLowerCase() === room.currentWord.toLowerCase()
5. Create Guess: { id: uuid, participantId, text, isCorrect, awardedPoints: 0, timestamp }
6. If isCorrect AND participant.hasScoredThisRound === false:
   - Set awardedPoints = 100
   - participant.score += 100
   - participant.hasScoredThisRound = true
7. Append guess to room.guesses
8. Save room, return { guess, correct: isCorrect, points: awardedPoints }
```

**Updated `toRoomSnapshot`**:
- Include `strokes: room.strokes ?? []`
- Include `guesses: room.guesses ?? []`
- `participants` already mapped — they now include `score` and `hasScoredThisRound`

**Pure function for guess validation** (satisfies IMM-1):

```typescript
export function checkGuess(text: string, secretWord: string): boolean {
  return text.trim().toLowerCase() === secretWord.toLowerCase();
}
```

#### 3. Route Changes (`api/rooms.ts`)

Three new routes on the existing `createRoomsRouter()`:

| Method | Path | Body | Success | Error |
|--------|------|------|---------|-------|
| POST | `/:code/draw` | `{ participantId, points }` | 200 `{ room }` | 404/403 |
| POST | `/:code/clear` | `{ participantId }` | 200 `{ room }` | 404/403 |
| POST | `/:code/guess` | `{ participantId, text }` | 200 `{ guess, correct, points }` | 404/403/400 |

#### 4. Schema Changes (`api/schemas.ts`)

```typescript
export const drawSchema = z.object({
  participantId: z.string().uuid(),
  points: z.array(z.object({ x: z.number(), y: z.number() })).min(1)
});

export const clearSchema = z.object({
  participantId: z.string().uuid()
});

export const guessSchema = z.object({
  participantId: z.string().uuid(),

});
```

#### 2. Canvas Component (`components/Canvas.tsx`) — NEW

- Receives props: `strokes`, `isDrawer`, `onDraw`, `onClear`
- Uses HTML5 `<canvas>` element
- **Drawer mode**: mousedown starts a stroke, mousemove extends it (draws locally), mouseup finalizes → calls `onDraw(points)`
- **Viewer mode**: renders remote strokes on every prop change (redraws canvas)
- Clear button visible only for drawer → calls `onClear()`
- Canvas dimensions: fixed width/height (e.g., 600x400) or responsive with aspect ratio
- Drawing style: black stroke, 2px width, round line caps

#### 3. GuessForm Component (`components/GuessForm.tsx`) — UPDATE

- Wire submit handler to call `api.submitGuess(code, participantId, text)`
- On response: show inline feedback ("Correct!" / "Incorrect")
- Clear input after submission
- Disable input after guessing correctly? No — spec allows unlimited guesses

#### 4. GamePage Updates (`pages/GamePage.tsx`)

- Replace canvas placeholder `<div>` with `<Canvas>` component
- Add guess history list below the canvas or in sidebar
- Wire drawer/clear/guess actions through roomStore methods

#### 5. Room Store Updates (`state/roomStore.ts`)

### Edge Cases & Error Handling

| Scenario | Handling |
|----------|----------|
| Non-drawer calls POST /draw | 403 — not drawer |
| Non-drawer calls POST /clear | 403 — not drawer |
| Drawer calls POST /guess | 403 — drawer cannot guess |
| Empty guess submitted | 400 — rejected with error message |
| Guess with only whitespace | Trimmed to empty → 400 — rejected |
| Game not started when drawing | 400 — room not in "game" status |
| Duplicate correct guess (same player) | Allowed (recorded), but 0 points awarded |
| Multiple strokes in one poll cycle | All strokes are in the array — guessers see them all |
| Canvas state when no strokes drawn | Empty array — guessers see blank canvas |
| Polling during active draw stroke | In-progress strokes not sent; only finalized strokes on server |
